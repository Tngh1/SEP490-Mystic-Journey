# 📖 Pixel Adventure Book UI: Fantasy RPG Kit
## PNG Resource README

Thank you for purchasing **Pixel Adventure Book UI: Fantasy RPG Kit**!
This document will help you get started quickly.

## 📦 What's Included

This package contains **183 pixel art style UI component sprites** in PNG format. All images have transparent backgrounds and are ready to use in any game engine or design tool.

## 🎨 Sprite Categories

### Icons (96)

- **Items** (6) — Item icons for RPG games
- **Pets** (8) — Cute creature/pet icons
- **System** (82) — Comprehensive system UI icons covering settings, navigation, status indicators, interactions, and more

### UI Components (72)

- **Backgrounds** (4) — Page and panel backgrounds
- **Badges** (4) — Status, notification, and rank badges
- **Buttons** (17) — Confirm, cancel, close, navigation, and more
- **Controls** (21) — Sliders, checkboxes, toggles, dropdowns, etc.
- **Decorations** (7) — Decorative elements to enrich your screens
- **InputFields** (1) — Text input field
- **Lists** (6) — List components for quest logs, item lists, etc.
- **Panels** (4) — Panel frames to contain your content

## 💡 9-Slice Compatible

Resizable resources such as panels, buttons, and frames are designed with 9-slice in mind. If your engine supports 9-slice (Unity, Godot, RPG Maker, etc.), apply it to scale these sprites freely without breaking corners or borders.
